Merge Haven — Static Local Edition 1.0.0
原游戏版本：1.510.15；整理日期：2026-10-29

这是可以直接由普通静态服务器提供的游戏目录。
入口为根目录 index.html。没有应用后端、代理、Node.js 运行时、npm 依赖、
在线账号、外部 SDK、CDN 素材依赖或需要临时改写文件的启动器。
没有 CSP 外网阻断规则，也没有替换浏览器 fetch、XHR 等 API。
完整目录可在本地 HTTP 服务器运行；放到静态托管后由该站点提供所有文件。
这不是 PWA，也不安装 service worker。

开始与语言
- 首次使用独立新存档，从开场和初始棋盘开始，默认 English。
- 设置 → Language → 简体中文；语言选择会随本地存档保存。
- 新版不读取上次 MSN / 启动器版本的测试存档。
- 压缩包不包含任何玩家进度或浏览器个人数据。

保存进度
- 原生进度自动保存在当前浏览器；设置 → Save data / 存档管理可导出、导入、重新开始。
- 更换域名、部署目录、浏览器或设备前，先导出 JSON 存档，再在新地址导入。
- 导入前校验游戏版本、格式和原生校验和；无效文件不会替换当前存档。
- 重新开始保留当前语言偏好。首次安装的默认语言始终为英文。
- 不要用清除站点数据的方式关闭游戏；无痕模式和浏览器清理可能删除本地进度。
- 同一存档打开多个标签时，新标签接管；旧标签停止保存并提示重新载入，避免相互覆盖。
- 原版最初的新手教学采用检查点：完成第一个订单后开始正常续玩。
  在第一订单完成前退出，会重新进行这段短引导；这是保留的原生初始化规则。

内容清理
- 游戏界面不提供广告、真钱购买、登录、云存档、社交聊天、排行榜、推广或安装入口。
- 已移除平台/广告 SDK 加载器、Firebase、原服务端 REST 传输和调用，以及在线支付配置。
- 已移除广告加速/翻倍、货币购买按钮、购买周任务、推送与隐藏调试购买热点。
- 保留合成、订单、房间装修、剧情、能量规则、本地货币商店、免费物品和独立单人活动。
- 保留必要的共享素材和兼容类型；未选择的平台的无执行路径文字可能仍在代码中。
  它们不会构成运行依赖，不能通过游戏界面进入。

静态部署
解压后，index.html、config.js、local-ui.js、local-ui.css、favicon.ico、assets/
应位于同一个发布目录。不要再套一层路径错误的空目录，也不要单独上传 index.html。
资源路径支持网站根目录和 /repository/ 这样的子目录。

GitHub Pages：发布这个目录中的文件即可，保留根目录 .nojekyll；无需构建游戏。
Cloudflare Pages：选择静态站点/无框架，把这个目录作为构建产物；无需 Functions、Worker 或数据库。
完整包超过 1,000 个文件。Cloudflare 网页拖放有 1,000 文件上限，使用 Git 集成或 Wrangler
上传整个目录；这是上传方式的限制，不是游戏运行依赖。单文件均小于 25 MiB。
本次没有创建仓库、上传或部署任何站点。
